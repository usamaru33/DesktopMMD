# DesktopMMD

デスクトップの隅にMMDモデルのキャラクターが住みつき、声や文字で話しかけると表情豊かに答えて読み上げてくれるアシスタントです。
ファイルを探したり、メモを書いたり、タイマーをかけたりといったPC作業も手伝ってくれます。話すほどあなたのことを覚えて、口調も少しずつ打ち解けていきます。

> 開発者向けの情報は [DEVELOPMENT.md](DEVELOPMENT.md) にあります。

## できること

- **話しかける:** キーを押しながら声で、または入力欄に文字で。返事は吹き出しに表示され、VOICEVOXの声で読み上げられます。口の動きは声に合わせて動きます。
- **表情と仕草:** 喜び・驚き・悲しみ・怒り・困り・照れ・考え中の表情と仕草で反応します。マウスを目で追い、まばたきや呼吸もします。頭をクリックすると撫でられた反応をします。
- **作業の手伝い:** ファイルの検索・読み取り・要約、メモの作成、ファイルの移動、アプリやWebページを開く、Web検索、タイマーとリマインダー、クリップボードの加工、画面に映っているものの説明。
- **覚える:** 会話の中から、あなたの好みや予定を覚えます。「覚えて」「忘れて」「それは違う」と言えば直せます。
- **声をかけてくれる:** 長時間の作業に休憩を提案したり、予定の少し前に知らせたりします（回数や時間帯は設定できます）。設定の「時報と休憩の声かけ」で、30分または1時間ごとに時刻を知らせて休憩を提案させることもできます。

## 必要なもの

| もの | 説明 |
| --- | --- |
| Windows 10 / 11（64bit） | |
| [VOICEVOX](https://voicevox.hiroshiba.jp/) | 声を作るソフトです。インストールしておけば、DesktopMMDの起動時に裏で自動的に起動します（DesktopMMDを終了すると一緒に止まります）。使えないときはWindows標準の音声で話します。代わりに [AivisSpeech](https://aivis-project.com/)（抑揚がより自然な、VOICEVOXと同じ使い方のソフト）も使えます（下の「声をより自然にする」）。 |
| Claude APIキー | 会話に使います。[Anthropicのコンソール](https://console.anthropic.com/settings/keys)で作成します。**使った分だけ料金がかかります**（下の「料金について」）。このPCのAIで会話だけするなら不要です（下の「このPCのAIで会話する」）。 |
| MMDモデル（PMXファイル） | キャラクターの体です。**アプリには含まれていません。** 自分で入手したモデルを、そのモデルの利用規約の範囲で使ってください。モデルが無くても、簡単な代わりのキャラクターで動きます。 |
| マイク | 声で話しかける場合 |
| （あれば）NVIDIAのGPU | 声の聞き取りが速く正確になります。無くても動きます。 |

## インストール

1. `DesktopMMD-Setup-0.4.0.exe` を実行します。
   - 「WindowsによってPCが保護されました」と出た場合は、「詳細情報」→「実行」を選んでください（このアプリは署名されていないため表示されます）。
2. インストール先を選んでインストールします。
3. DesktopMMDを起動します。VOICEVOXは自動で起動します。
4. 次からは、Windowsにサインインすると自動で起動します（下の「PCを起動したとき」）。

起動するたびに、GitHubのリリースに新しい版がないか確認し、あれば自動でダウンロードして更新し、再起動します（設定の拡張設定にある「起動時に新しい版を確認して自動で更新」をOFFにすると確認しません）。いま使っている版は、設定画面の一番下の「バージョン」とタスクトレイのメニューの先頭で確認でき、「今すぐ確認」ボタンでその場で最新版を確認・更新できます。

## はじめての設定

初回起動時に「はじめに」画面が開きます。順番に設定してください。必要なのは1の「会話のAI」だけで、ほかは「あとで設定する」で飛ばせます。

1. **会話のAI:** 「Claude API」か「このPCのAI（Ollama）」のどちらかを選びます。Claude APIなら、APIキーを貼り付けて「保存してClaudeを使う」を押します。キーはWindowsの暗号化機能で保存され、画面に再表示されることはありません。APIキーを使わず会話だけする場合は「このPCのAIを使う」を押します（下の「このPCのAIで会話する」）。
2. **キャラクター:** 使いたいMMDモデルのPMXファイルを選びます。ファイルは読み込むだけで、書き換えたりコピーしたりはしません。選ばなくても代わりの簡単なアバターで動きます。
3. **声:** VOICEVOXにつながるかを自動で確かめます。つながらなければ「VOICEVOXを起動する」か「VOICEVOXを入手」を押します。入れていなくても、Windows標準の声で話します。声の種類は、あとで「調声」画面で選べます。
4. **マイク:** 「テスト開始」を押して話しかけ、バーが動けばOKです。
5. **呼び名:** キャラクターがあなたを何と呼ぶかを決めます。
6. **使い方:** 話しかけ方が表示されます。「使い始める」で完了です。

あとから設定画面を開くと、いちばん上の「使い始めの確認」で、足りないものとその設定ボタンを確認できます。

### 設定画面の「拡張設定」

設定画面には、ふだんはよく使う項目だけが出ています。右上の「拡張設定」をONにすると、次のような細かい設定も各カードの下に出てきます。

- キャラクター: 一人称、性格と口調、キャラクタースキル（skill.md）、モーフ名の上書き、感情別モーション、標準の感情モーション
- 会話のAI: 会話・声かけ・内部処理に使うモデル、考える深さ、キャッシュ、今月の内訳
- 音声: 文字起こしのモデルと実行デバイス、ほかのホットキー、音質フィルター、読み上げエンジンの場所
- 表示: 描画の上限（fps）、視線の上限角度、揺れ物、ハードウェアアクセラレーション、自動更新
- そのほか: 声かけの上限と静かな時間帯、Googleカレンダー、起動を許すアプリ、ツールごとの権限、コマンド実行、MCPサーバー
- 調声画面: 「サンプルから」「感情別」「定型文」のタブ

> 初めて声の機能を使うときは、聞き取り用のデータ（約1.8GB）を自動でダウンロードします。数分かかることがあり、その間は文字で話しかけてください。

## 使い方

### 話しかける

| やりたいこと | 操作 |
| --- | --- |
| 声で話しかける | **Ctrl+Alt+Space を押している間**話し、離すと送ります |
| 文字で話しかける | Ctrl+Alt+Space を**短く押す**か、キャラクターをダブルクリックして入力欄に書き、Enter |
| ファイルについて聞く | ファイルをキャラクターにドラッグ＆ドロップ |
| 話を止める | 話している途中に話しかける、または Esc |

### キャラクターを動かす

| やりたいこと | 操作 |
| --- | --- |
| 移動 | キャラクターをドラッグ |
| 大きさを変える | キャラクターの上でマウスホイール（50%〜200%） |
| メニュー | キャラクターを右クリック（入力欄、位置のリセット、サイズ、ミュート、管理画面、隠す） |
| 表示 / 非表示 | Ctrl+Alt+H、またはタスクトレイのアイコンをクリック |
| ミュート（文字だけで返事） | Ctrl+Alt+M |

キャラクター以外の透明な部分はクリックが後ろのウィンドウに通るので、作業の邪魔になりません。
ほかのアプリに切り替えたり、ウィンドウを最小化したりしても、キャラクターは常に手前に表示されたままです。
ゲームや動画を全画面で表示している間だけは、自動で隠れて話しかけてこなくなります（設定の「全画面のアプリを使っている間は隠れる」をOFFにすると、そのときも表示したままになります）。

感情に合わせて、うなずき・首のかしげ・のけぞりなどの動きが付きます（標準のモーションは、このアプリが自分で作った動きで、腕や足は動かしません）。キャラクターごとに自分のVMDを指定すると、そちらが優先されます。設定の「標準の感情モーション」をOFFにすると、より簡単な動きになります。

吹き出しは頭の上に出て、読み終わって2秒ほどでふわっと消えます（マウスを乗せている間は消えません）。設定の「会話の吹き出しを表示」をOFFにすると出さなくなります（読み上げは続きます）。

キャラクターは目でマウスカーソルを追います。画面の端のほうで白目が目立つときは、設定の「視線の上限角度」を小さくしてください（0にすると正面を向いたままになります）。

### Googleカレンダーの予定を知らせてもらう

予定の少し前に、キャラクターが声をかけます。読み取るだけで、予定の追加や変更はしません。

1. Googleカレンダーをブラウザで開き、「設定」→ 予定を読ませたいカレンダーを選ぶ →「カレンダーの統合」→「iCal形式の非公開URL」をコピーします。
2. 管理画面の「設定」→「Googleカレンダー」に貼り付けて「登録」を押し、「予定をお知らせする」をONにします。
3. 何分前に知らせるか（5〜30分前）も同じ場所で選べます。「今日の予定は？」と聞くと、答えてくれます。

この非公開URLを知っている人は予定を見られます。他人に見せないでください（アプリはこのPCの中で暗号化して保存します）。URLを作り直すと古いURLは使えなくなります。15分ごとに更新し、通信は `calendar.google.com` だけです。

### PCを起動したとき

Windowsにサインインすると、DesktopMMDが自動で起動し、VOICEVOXも裏で起動します。

- 自動起動をやめるには、設定画面の「表示と動作」→「Windows起動時に自動起動」をOFFにします（Windowsの「設定」→「アプリ」→「スタートアップ」でも切り替えられます）。
- VOICEVOXを一緒に起動しないようにするには、設定画面で「拡張設定」をONにし、「読み上げ」→「アプリ起動時に読み上げエンジンも起動する」をOFFにします。VOICEVOXを標準以外の場所に入れた場合は、同じ場所の「エンジンの場所」で指定してください。
- 調声画面でAivisSpeechを選んでいる場合は、VOICEVOXの代わりにAivisSpeechを同じように起動します。
- すでにVOICEVOX（エディタ）を開いている場合はそれを使い、二重には起動しません。DesktopMMDを終了しても、自分で開いたVOICEVOXはそのままです。

### タスクトレイのメニュー

表示/非表示、ミュート、マイクのON/OFF、おやすみモード（話しかけてこなくなります）、集中モード（指定した時間だけ静かにします）、キャラクターのモード（skill.md にモードがある場合）、各管理画面、この説明書（使い方）、終了ができます。
この説明書はインストール先のフォルダにも `README.html` として入っています。

### 集中モード

「25分集中したい」「作業に集中するから静かにして」と話しかけるか、タスクトレイの「集中モード」（25分・50分・90分）で始めます。

- 集中している間は、声かけ（挨拶・休憩の提案・雑談・時報）を止めて静かにします。自分で頼んだタイマーとリマインダーだけは、いつもどおり鳴ります。
- 時間になると、お疲れさまの一言と、短い休憩の提案をします。途中でやめたいときは「集中やめる」と言うか、トレイの「集中モードを終わる」を選びます。
- 話しかければ、集中中でも普通に答えます。アプリを終了すると集中モードも終わります。
- 声で頼むには、ツールが使えるAI（Claude API、または「ローカルAIでも作業を頼む」をONにしたローカルAI）が必要です。会話だけのローカルAIのときは、トレイから始めてください。

### 作業を頼むとき（確認と承認）

キャラクターが勝手に危ないことをしないよう、作業は3段階で扱われます。

| 種類 | 例 | 動き |
| --- | --- | --- |
| 自動 | ファイルを読む・探す、Web検索、タイマー | すぐに実行します |
| 確認 | ファイルの作成・移動、アプリやWebページを開く、クリップボード、画面の撮影 | 確認カードが出ます。ボタンか、声で「いいよ」「だめ」と答えます。「今日は常に許可」も選べます |
| 承認 | ファイルの削除（ごみ箱へ）、コマンドの実行 | 対象がすべて表示され、**ボタンのクリックでのみ**許可できます（声では許可できません） |

- 60秒答えなければ、実行せずに取り消されます。
- ファイルを読み書きできるのは「許可フォルダ」の中だけです（最初は「ドキュメント」と「デスクトップ」）。設定画面で変えられます。ドロップしたファイルは、そのファイルだけ読むことができます。
- ファイルの作成・上書き・移動は「作業履歴」画面から取り消せます。上書き前の内容は30日間保管されます。
- ファイルやWebページの中に「〇〇を削除せよ」などと書かれていても、キャラクターはそれに従わないよう作られています。

## 管理画面

キャラクターの右クリックメニューか、タスクトレイから開きます。

| 画面 | できること |
| --- | --- |
| 設定 | APIキー、使うAIモデル、月の利用額の上限、キャラクター（名前・一人称・性格・モデル）、音声入力の方式とホットキー、許可フォルダ、起動を許すアプリ、声かけの頻度と静かな時間帯、表示（fps・吹き出し・視線の上限角度・揺れ物）、自動更新、自動起動、読み上げエンジンの自動起動と場所、音質フィルター、プライバシー |
| 調声 | 読み上げエンジン（VOICEVOX / AivisSpeech）、声の種類、サンプル音声からの自動調声、話す速さ・高さ・抑揚・音量・間、感情ごとの声の変化（感情に合うスタイルへの自動切り替え）、読み間違いを直す単語辞書、挨拶などの定型文のアクセント。どれもその場で試聴できます（「モデルに話させる」でキャラクターが話します） |
| 記憶 | 覚えていることの一覧・編集・削除・追加、JSONへの書き出し、すべて消去。親密度と機嫌もここで見られます |
| 会話履歴 | 日付ごとの会話と全文検索 |
| 作業履歴 | 実行した作業・結果と取り消し |

### サンプル音声から声を合わせる（自動調声）

「調声」画面の「サンプルから」タブで、似せたい声の音声ファイル（mp3・wav・m4a・ogg）を選んで「近い声を探す」を押すと、いま使っているエンジン（VOICEVOX / AivisSpeech）の声の中から声色と高さが近いものを探し、話す速さ・高さ・抑揚をサンプルに合わせた候補を3つ出します。

1. 音声ファイルをドロップするか、クリックして選びます（先頭20秒を使います）。BGMや効果音の無い、1人の話し声だけの5〜20秒くらいの音声がいちばんよく合います。
2. 「話している内容」は空のままで構いません（音声認識で書き起こします）。分かっていれば入れると、話す速さが正確になります。
3. 「探す範囲」は「すべての話者から」（数分かかります）か「今の話者のスタイルから」（すぐ終わります）を選びます。
4. 候補を「▶ 試聴」で聞き比べ、「この声にする」→ 右上の「保存」で確定します。あとから「基本の調声」タブで細かく直せます。

声そのものをコピーする機能ではなく、エンジンにある声と調声値を選ぶ機能です。人の声は合成音声より抑揚が大きいため、自然に聞こえる範囲（話速0.75〜1.5・抑揚0.6〜1.5）に収めた値を出します。「すべての話者から」探すとエンジンが全部の声を読み込むため、メモリを数GB使います（エンジンを再起動すると元に戻ります）。

### 声をより自然にする

高い音がかすれる、抑揚がわざとらしい、と感じるときは次を試してください。

1. **抑揚と話速を目安の範囲に戻す:** 「調声」→「基本の調声」で、抑揚が1.5より大きい、または話速が0.75より遅いと注意が出ます。「目安の範囲に収める」で直せます。抑揚を強くするほど高い音が合成の得意な音域を超えて崩れやすく、話速を遅くするほど母音が間延びします。
2. **感情はスタイルで出す:** 「調声」→「感情別」の「感情に合うスタイルがあれば、それで話す」（最初からON）。喜び・悲しみ・怒りなどのスタイルを持つ話者なら、音を高くして感情を出す代わりに、その感情で録られたスタイルに切り替えます。
3. **音質フィルター:** 設定の「読み上げ」→「音質フィルター」。再生の前に耳障りな高い音を少し削り、音量をそろえます（最初から「やわらかく」）。「部屋の響き」はごく短い残響も足します。
4. **AivisSpeechを使う:** [AivisSpeech](https://aivis-project.com/)をインストールし、「調声」→「声の選択」の「読み上げエンジン」で「AivisSpeech」を選んで保存します。文の意味に合わせて抑揚を付けるので、VOICEVOXより自然に聞こえやすくなります。音の高さの指定と定型文のアクセント調整は使えず、口の動きは声の大きさに合わせます。

VOICEVOXのままでも、抑揚を強くしたときに文のもともとの音域から大きくはみ出す音は、自動で抑えます。

### 話し方が親しくなっていく仕組み

会話を重ねると「親密度」が上がり、初対面 → 顔なじみ → 親しい → 相棒 と段階が進みます。段階が進むと口調がくだけ、自分から話題を振るようにもなります。1日に上がる量には上限があります。

### 声で呼びかける（常時待受け）

設定の「音声入力」を「名前で呼びかけ」にすると、キーを押さなくても、キャラクターの名前（または設定した言葉）から話し始めるだけで聞き取ります。マイクは常にONになります。

## キャラクタースキルの書き方

キャラクターの性格や口調は、キャラクターごとの **スキルファイル**（`skill.md`）に書きます。モデルや声と一緒に、話し方もキャラクターごとに切り替えられるようにするための仕組みです。

- skill.md が無いキャラクターでは、これまでどおり設定画面の「性格と口調」が使われます。
- skill.md を保存すると、アプリが自動で読み直し、次の発話から反映されます。
- 書き方に誤り（エラー）があるあいだは skill.md は使われず、管理画面の設定 > キャラクターにエラーの一覧が出ます。

### 要点

- 置き場所は `%APPDATA%\mmd-assistant\characters\<id>\skill.md`。`<id>` はキャラクターのフォルダ名で、ファイル先頭の `id` と同じにします。
- 先頭に名前などの基本情報（`---` で囲む）を書き、続けて次の見出しを **この名前・この順序** で書きます。
  - 必須: 話し方 / 性格 / 感情の出方 / 場面別 / 関係性 / 例文 / 言わないこと
  - 任意: 声と動き / 背景 / モード
- 例文は `- 場面: [感情:強さ] セリフ` の形で3〜5件。感情は neutral / happy / surprised / sad / angry / troubled / shy / thinking の8つです。
- 関係性は、親密度の4段階（初対面 / 顔なじみ / 親しい / 相棒）ごとに書きます。
- 本文は全体で **1,500〜2,500 文字** が目安です。長いほど返事が遅く、料金も上がります。
- 返事の形式・作業の権限と承認・記憶の扱い・安全のルールはアプリ側で固定されていて、スキルでは変えられません（変えようとする記述は検証でエラーになります）。
- セリフは自分で考えて書いてください。既存の作品のキャラクターやセリフを写さないでください。

### 書き始め方

1. 管理画面の設定 > キャラクターで「今の設定から下書きを作る」（または「サンプルから作る」）を押します。skill.md が作られてエディタで開きます。
2. 各項目を埋めて保存します。エラーがあれば管理画面に一覧が出ます。
3. `## モード` を書いたキャラクターは、タスクトレイの「キャラクターのモード」（または管理画面）でモードを切り替えられます。

開発環境では、検証ツールでも確認できます（手順は [DEVELOPMENT.md](DEVELOPMENT.md)）。

```powershell
npx tsx scripts/validate-skill.ts characters/<id>/skill.md
```

詳しい書式（各項目の書き方、良い例と悪い例、文字数の目安、よくある失敗）は [docs/CHARACTER_SKILL_FORMAT.md](docs/CHARACTER_SKILL_FORMAT.md) にあります。

## ふりかえり日記

毎日決まった時刻に、その日の会話・した作業・覚えたこと・明日の予定をまとめた「ふりかえり」を、Markdownのファイルで保存します（設定の「ふりかえり日記」でONにします。最初はOFFです）。

- **保存先:** 許可フォルダの中のフォルダです（最初は「ドキュメント」の `DesktopMMD日記`）。ObsidianのVaultなどを指定すれば、そのままメモとして使えます。1日1ファイル（`2026-10-11.md`）です。
- **時刻:** 最初は22:30です。PCが起動していなかったときは、次に起動したときに前の日の分を書きます。「今日の分を今すぐ作る」ボタンで、その場で作り直すこともできます（このアプリが作ったファイルだけを作り直します）。
- **同じ名前のファイルがあるとき:** あなたが作ったファイルは上書きせず、`2026-10-11-2.md` のように別の名前で保存します。
- **材料にするもの:** その日の会話、実行した作業の種類、その日に覚えたこと、明日が期日の予定。「この会話は記憶しないで」と言った会話と、会話の保存をOFFにしている間の会話は使いません。声かけ（アシスタントから話しかけたもの）も材料にしません。
- **AIに送られる内容:** 日記を作るために、その日の会話の要約がAIに送られます（APIキーがあればClaude、無ければこのPCのAI）。作ったファイルは、このPCのフォルダに書くだけで、どこにも送りません。

## 料金について

会話にはClaudeのAPIを使うため、話した量に応じて料金がかかります（Anthropicからの請求）。

- 設定画面に今月の利用額の目安が表示されます。
- 月の上限額（最初は20ドル）の80%で知らせ、100%に達すると安い軽量モデルに切り替えます。
- 返事を考えるのは高性能なモデル（Sonnet）、挨拶や休憩の提案などの声かけと記憶の整理は安いモデル（Haiku）で行います。どれに使うモデルも設定画面（拡張設定）で変えられます。
- 設定画面（拡張設定）の「今月の内訳」で、会話の返答・作業のあとの返答・声かけ・記憶の整理などに、それぞれいくら使ったかを確認できます。
- 毎回送るキャラクター設定や機能の説明は「キャッシュ」に1時間残し、間をあけて話しかけたときも安く済むようにしています（設定の「キャッシュの保持時間」で5分にも変えられます）。
- 設定の「月の上限額」に達しても、安いモデルに切り替わるだけで利用は止まりません。確実に一定額で止めたいときは、Anthropicのコンソールで前払いのクレジットだけを使うか、利用上限を設定してください。

## このPCのAIで会話する

会話を、Claude APIの代わりに、このPCで動くAI（[Ollama](https://ollama.com/)）にできます。料金がかからず、会話の内容がインターネットに出ません。

- **使い方:** Ollamaをインストールして `ollama pull qwen3:8b` を実行し、設定の「会話のAI」で「このPCのAI」を選びます。「接続を確認」でつながっているか確かめられます。
- **向いているPC:** NVIDIAのGPUでVRAMが10GB以上なら快適です（RTX 4070 SUPERで、返事の最初の文字まで約0.05秒、1秒に約76文字ほど）。設定の「このPCの診断」に、このPCに合うかが表示されます。GPUが無いPCや、VRAMが5GB未満のPCは、Claude APIをおすすめします。
- **できること・できないこと:** 会話と読み上げ、表情の変化は同じように動きます。既定では**ファイルの操作・タイマー・画面の確認など「作業の代行」は使えません**（小さなAIは、道具を正しく選べないことがあるためです）。頼むと、できないと正直に答えます。Web検索はClaude APIのときだけです。
- **作業も頼む（実験的）:** 設定の「ローカルAIでも作業を頼む」をONにすると、ファイル・タイマー・記憶などのツールもローカルのAIで使えます。8Bのモデルで10回中9回ほど正しく使えますが、間違えたり、やったと言うだけで実行しないことがあります。作業を頼む発話のときだけ、返事の前に2〜3秒考えます。実行前の確認と承認はClaude APIのときと同じように必ず出ます。
- **記憶:** 会話からの記憶の自動抽出は、APIキーがあればClaude、無ければこのPCのAIで行います。小さなAIは抽出の精度が下がることがあります。
- **声かけだけローカルにする:** Claude APIで会話していても、設定の「声かけだけはこのPCのAIを使う」をONにすると、挨拶・休憩の提案・リマインダーなど短いセリフはこのPCのAIで作ります。その分の料金がかからず、声かけの内容がインターネットに出ません。Ollamaに接続できないときは、自動でClaudeに戻ります（声かけは1〜2文なので、小さなAIでも十分です）。
- **最初の返事が遅いとき:** AIをメモリに読み込むのに1分ほどかかります。アプリの起動時に先に読み込んでおきます。
- OllamaのURLを別のPCに変えると、会話の内容がそのPCに送られます。自分の管理するPCだけを指定してください。

## プライバシー

- 記憶・会話の記録・設定はすべてこのPCの中（`%APPDATA%\mmd-assistant`）に保存されます。
- Googleカレンダーを連携すると、予定の取得のために `calendar.google.com` に接続します。予定の題名や場所は、声かけや「今日の予定は？」への返事のためにClaude APIにも送られます。
- ふりかえり日記をONにすると、その日の会話の要約をAIに送って日記を作ります（上の「ふりかえり日記」）。
- 外部に送られるのは、Claude APIへの会話（「このPCのAI」を選んでいる間、会話は送られません）（関連する記憶の一部、ツールの結果を含む）と、Web検索の検索語だけです。このほか、自動更新のために起動時にGitHubへ最新版の問い合わせをします（記憶や会話は送りません）。
- 声は文字に起こしたあとすぐに破棄され、保存されません。画面の撮影も保存しません。
- 使っているアプリ名を声かけのきっかけに使う機能は、最初はOFFです。ONにしてもウィンドウのタイトルは使いません。
- 「この会話は記憶しないで」と言うと、その会話からは何も覚えません。
- 記憶画面の「すべて消去」で、記憶・会話の記録・親密度をまとめて消せます。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 「APIキーが設定されていない」と言われる | 設定画面でAPIキーを登録してください。APIキーを使わないなら「会話のAI」を「このPCのAI」にしてください |
| 「ローカルのAIから返事がありません」と言われる | Ollamaが起動しているか、設定の「会話のAI」で「接続を確認」を押して確かめてください。「モデルがありません」と出たら、表示されたコマンド（`ollama pull …`）を実行します |
| 声がWindows標準の声になる | 設定の「読み上げ」で「エンジンの状態」を確認し、未接続なら「今すぐ起動」を押してください。「エンジンの場所」にエンジンが見つからないと表示される場合は、VOICEVOX（またはAivisSpeech）をインストールするか場所を指定してください。起動すれば30秒ほどで自動的に戻ります |
| 高い音がかすれる・抑揚が不自然 | 上の「声をより自然にする」を試してください |
| PCを起動しても立ち上がらない | 設定の「Windows起動時に自動起動」がONか、Windowsの「設定」→「アプリ」→「スタートアップ」で DesktopMMD がオンになっているか確認してください |
| 自動調声で「声の高さを読み取れませんでした」と出る | BGMや雑音が大きい音声です。話し声だけの部分を切り出したファイルを使ってください |
| 声で話しかけても反応しない | 初回のダウンロード中かもしれません（設定画面の「使い始めの確認」で「音声認識」の状態を確認）。マイクがONか、トレイのメニューも確認してください |
| キャラクターの後ろが黒くなる | 設定の「ハードウェアアクセラレーション」をOFFにして、アプリを再起動してください |
| 表情が出ない部分がある | モデルによって表情の名前が違います。設定画面の「モデル」欄に見つからない表情が表示されるので、「拡張設定」をONにして「モーフ名の上書き」でそのモデルでの名前を指定してください |
| ホットキーが効かない | 他のアプリと重なっています（起動時に通知されます）。設定画面でキーを変えてください |
| キャラクターが見えない | 全画面のアプリ（ゲーム・動画・スライドショーなど）を使っている間は自動で隠れ、終了すると戻ります（常に表示したいときは設定の「全画面のアプリを使っている間は隠れる」をOFF）。それ以外のときは Ctrl+Alt+H かトレイのアイコンで表示できます |
| 声かけがうるさい | 設定の「能動発話」で回数を減らすか、静かな時間帯を設定するか、トレイの「おやすみモード」や「集中モード」を使ってください |
| 動作が重い | 設定の「描画の上限（fps）」を下げるか、「揺れ物」をOFFにしてください |

うまく動かないときは `%APPDATA%\mmd-assistant\logs` のログを確認してください（会話の内容やAPIキーはログに書かれません）。

## アンインストール

Windowsの「設定」→「アプリ」から DesktopMMD をアンインストールします。自動起動の登録も一緒に消えます。
記憶・設定・APIキーは `%APPDATA%\mmd-assistant` に残ります。すべて消したい場合は、このフォルダも削除してください。
